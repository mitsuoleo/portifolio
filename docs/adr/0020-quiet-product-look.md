# Scientific Minimal Look

The night navy instrument Look is retired. Index uses an off-white technological field, ink text, and cobalt for action and identity. Aqua is reserved for the computational core and live-state highlights, never for small text on the light ground. Typography: Syne (display), IBM Plex Mono (system codes), Source Serif 4 (editorial), IBM Plex Sans (chrome). Retro workstation details stay secondary (codes, thin rules). Frutiger Aero is a moment on the 3D artifact, not a glassmorphism skin. Terminal is not the interface.
