# Observa replaces the planned Commerce Intelligence and Catalog pages

Observa is the anchor System (`SYS/001`) and the Portfolio's full nine-section study. Its public Evidence Repo documents a reproducible local order journey, observability, recovery checks, results, and explicit limits. Order Pipeline and Link Shortener remain secondary Systems; PromptVault remains in Lab. The Owner chose to replace the planned Commerce Intelligence and Catalog pages with Observa, so their pages and claims are removed from the current Portfolio.

This supersedes the launch lineup and publication gate in ADRs 0012 and 0014, and retires the Catalog-specific decisions in ADRs 0015 and 0017 from the current Portfolio scope. The trade-off is a narrower data analytics story in exchange for an anchor a Technical Reviewer can clone and inspect today. The Portfolio still requires a verified deployed URL before it can be cited in a CV.
