# Mercado One leads the Portfolio

Mercado One is the first System on Index and Work and the System named in the status block. Its public repository at `Fatech-Ypiranga/Mercado-One-Java` documents a Java/Spring Boot API, Angular admin, and JavaFX desktop POS with local SQLite sales and synchronization. The Portfolio describes it as an in-progress MVP and gives it a short System page.

Observa keeps its nine-section technical study and its public Evidence Repo. This decision supersedes only the anchor and ordering established in ADR 0021; that record remains as the history of why Observa replaced the earlier planned lineup. Public project numbers are removed from the interface.
